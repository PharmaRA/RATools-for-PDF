# 2026-11-08 代码审查

基准：`ad95c8c`（v0.8.1）及当时工作区。审查范围为 `ratools_pdf/` 的 PDF 内核、控制器、UI、服务和配置，以及构建脚本、工作流和直接相关测试。用户已有 `ratools_pdf/ui/theme.py` 修改及 `.playwright-mcp/`，不属于本次修复提交。

发现共 18 项：12 项 P1（优先修复），6 项 P2（随后修复）。编号与审查回复保持一致，执行顺序和当前状态见[质量改进计划](../plans/quality-improvement.md)。本文件记录审查时事实，不以修复后的行号替代原始定位。

## R-01 / P1：失败清理会删除已有输出

- 定位：`controllers/workers.py:156–162,184–185,203–221`。
- 触发：重复使用输出目录，新任务在写入前失败、停止或跳过。
- 原因：无条件删除正式输出及其 `.tmp.pdf`，没有本轮所有权判断。
- 证据：调用实际 `_finish_process_task()`，mock 文件操作后确认会删除旧正式输出及旧临时文件；没有执行真实删除。
- 修复方向：独立任务临时目录；成功后提交结果，失败只回收本轮临时内容；拒绝输入输出别名。
- 验收：写入前失败、写入中失败、停止、跳过均保留旧输出；成功可提交新内容；覆盖原文件失败保留原文档；临时内容进入回收站。

## R-02 / P1：链接改色破坏文本显示操作

- 定位：`pdf/hyperlink_styles.py:164–170`。
- 触发：文本块使用默认或继承颜色，没有 `rg/g` 指令。
- 原因：颜色指令插在文本操作数与 `Tj/TJ` 之间。
- 证据：真实内存 PDF 的 `(LINK) Tj` 被改为 `(LINK) 0 0 1 rg Tj`；文字提取从 `LINK` 变为空，函数仍报告修改成功。
- 修复方向：正确识别内容流操作边界，在完整显示操作前设置颜色。
- 验收：`Tj/TJ`、默认/继承颜色、带转义括号文本；文字与渲染内容保全，目标颜色正确。

## R-03 / P1：纸张适配裁切旋转页

- 定位：`pdf/page_layout.py:39,73–82`。
- 触发：90°/270° 旋转页需要调整纸张尺寸。
- 原因：用旋转后尺寸计算，再直接修改未旋转内容流与 MediaBox，保留 `/Rotate`。
- 证据：200×400、Rotate=90 的页面以 600×800 为目标适配后方向错误，`MARKER` 文字被裁出页面。
- 修复方向：统一页面坐标系并保留方向及内容。
- 验收：0/90/180/270 度、横竖页面，内容、批注、链接位置及渲染一致性。

## R-04 / P1：缩放后导航目标错误

- 定位：`pdf/page_layout.py:60–63,108–135`。
- 触发：有书签的页面缩放；或不缩放源页指向需要缩放的目标页。
- 原因：改变 MediaBox 后才读取书签；按源页是否缩放跳过链接更新。
- 证据：目标 `(20,100)` 应变为 `(40,200)`，书签实际为 `(40,1000)`，跨页链接为 `(20,500)`。
- 修复方向：变换前保存导航；所有页面变换后统一更新所有目标。
- 验收：书签、同页/跨页链接、源页不变而目标变化、旋转目标及命名目标。

## R-05 / P1：压缩移除透明遮罩

- 定位：`pdf/processor.py:851,903–904`。
- 触发：图像通过独立 `SMask/Mask` 表达透明效果。
- 原因：提取时未合并遮罩，回写 JPEG 后清掉遮罩。
- 证据：真实内存 PDF 中半透明红图叠于蓝底，压缩后像素从 `(128,0,126)` 变为 `(254,0,0)`。
- 修复方向：保留并正确处理透明信息，不能支持的类型明确跳过。
- 验收：透明背景、软遮罩、颜色键遮罩及普通图像；渲染允许压缩误差但不能丢失透明效果。

## R-06 / P1：动态清理误删名称树且漏删脚本

- 定位：`pdf/processor.py:746–748`；预检 `pdf/precheck.py:1005`。
- 触发：Names 同时有 JavaScript、Dests、EmbeddedFiles；或脚本位于 OpenAction。
- 原因：将整个 Names 设为 null，没有精确清理动态入口。
- 证据：真实内存 PDF 序列化重开后命名书签悬空、附件从 1 变为 0；另一个 OpenAction JavaScript 保留。
- 修复方向：保留合法名称树分支，清理支持范围内的脚本/动态入口。
- 验收：仅清动态时附件和命名跳转保全；Names/JavaScript、OpenAction、AA 及支持的动态注释分别验证。

## R-07 / P1：签名烘焙失败仍删除控件

- 定位：`pdf/signature_baker.py:214–245`。
- 触发：外观与页面裁剪均失败，或写入外观失败。
- 原因：先删除控件、累计成功，异常兜底仍删除控件。
- 证据：mock 两条渲染路径失败，返回 1，删除 1 次，插图 0 次，保存 1 次。
- 修复方向：成功写入外观后再删除，失败不得计为成功或保存丢失外观的结果。
- 验收：两类渲染失败、插图失败、不可见签名和成功签名；原始文件及可见外观保全。

## R-08 / P1：同名输出碰撞

- 定位：`controllers/workers.py:95–99`、`controllers/io_actions.py:5–11,57–64`、`ui/dialogs/page_assembly_dialog.py:80`、`ui/dialogs/security_center_dialog.py:138`。
- 触发：普通批处理/IO 跨盘同名；拆分/解密不同目录同名。
- 原因：跨盘缺公共根时平铺，拆分/解密只使用 basename。
- 证据：实际路径函数及 worker mock 将不同来源的 report.pdf 写向同一路径；解密仍统计成功 2。未真实覆盖磁盘内容。
- 修复方向：统一规划整批最终路径、冲突检查，保留来源信息，避免目标占用队列输入。
- 验收：同盘/跨盘同名、重命名后碰撞、大小写别名、输出与输入冲突；失败不写任何任务结果。

## R-09 / P1：重复入队使并行任务失联

- 定位：`controllers/main_controller.py:296,305–306`、`controllers/workers.py:321`。
- 触发：同次添加文件和包含它的目录，或路径大小写别名。
- 原因：只对旧队列去重；运行任务按路径存入字典覆盖先前任务。
- 证据：队列 2 条、节点字典 1 条；并行启动 2、完成 1，首任务未 join/关闭连接。
- 修复方向：规范化绝对路径逐项去重，任务用独立标识管理。
- 验收：重复路径、文件与父目录、大小写别名；每个已启动进程都可停止和回收。

## R-10 / P1：并行异常不回收已启动进程

- 定位：`controllers/workers.py:318–320,379–380`。
- 触发：后续任务启动或通信异常时，前面的任务仍在运行。
- 原因：外层异常仅发错误，没有 finally 收尾。
- 证据：第二项 spawn 失败，首进程 terminate/join/连接关闭均为 0。
- 修复方向：异常路径回收全部已注册任务，为具体失败任务记录终态。
- 验收：启动、poll、recv、提交异常和用户停止；进程/连接全部收尾，失败可重试。

## R-11 / P1：IO 任务缺少互斥

- 定位：`controllers/io_controller.py:57–98`、`controllers/main_controller.py:121–135`。
- 触发：主任务运行中启动 IO，或 IO 未完成时再次启动、清队列。
- 原因：IO 未纳入统一 busy 判断，重复赋值覆盖 worker 引用。
- 证据：主任务 running 时两次导出均启动，IO running 时 ensure_idle 返回 True。
- 修复方向：统一 busy 检查和 UI 入口状态，直到线程结束才释放句柄。
- 验收：IO 与主处理/预检/检测互斥，重复启动和队列操作受保护，成功失败均恢复。

## R-12 / P1：关闭绕过运行保护

- 定位：`ui/dialogs/base.py:67`、`ui/dialogs/overlay_dialog.py:320`、`ui/main_window.py:714`；app/main_controller 缺统一 shutdown。
- 触发：运行中点顶部关闭，再退出应用。
- 原因：只禁底部关闭按钮，reject/closeEvent 未协调 worker。
- 证据：真实 Qt 内存测试中底部按钮禁用、顶部可用，关闭后线程仍运行。未故意触发进程崩溃。
- 修复方向：统一窗口关闭守卫及主应用任务收尾。
- 验收：顶部关闭、Escape、系统关闭、主窗口退出；全部线程/子进程安全结束后销毁。
