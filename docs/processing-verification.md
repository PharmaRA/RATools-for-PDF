# 处理计划预览与输出验证

点击“开始处理”后，RATools 会先打开“处理计划预览”。预览只读取 PDF 结构和文件指纹，不写入 PDF。每个文件会显示相对身份、所选规则、预检命中/未命中/不支持预检、执行或跳过及原因，并提示签名、表单、附件和可能的几何变化。

点击“取消”会停止只读检查并等待后台线程安全退出；不会创建输出目录，也不会修改原 PDF。确认后，程序会再次检查当前忙碌状态、规则选项、压缩参数和输入文件指纹。输入文件、选项或配置版本发生变化时，计划失效，文件会被拒绝执行并要求重新预检。

处理结果先写入受控临时目录。发布前会检查临时 PDF 能否保存后重开，并比较以下结构事实：SHA-256、字节数、页数、页面尺寸/旋转、书签、链接、批注（包括 RichMedia/Movie/Sound/3D）、附件、表单、签名字段/签名存在性和 PDF 版本。验证失败时保留已有输出，不发布临时结果；临时目录按现有安全策略移入回收站，无法回收时保留并报告位置。

停止或跳过请求在结构扫描期间到达时，会在 `os.replace` 前再次检查。请求生效后输出保持未发布，终态分别为“已停止”或“已跳过”。预期的几何、批注和 PDF 版本变化会单独记录为预期结构变化；未知检查显示 `not_verified`，不会显示“验证通过”。当前 PD-07 已接入实际规则结果及有限独立后置检查，范围见[规则结果说明](rule-results.md)；历史批次或未观测/未检查的规则继续保留 `unknown/null` / `not_verified`。

批次证据保留在当前主窗口内存中，可供后续审计导出使用。重试会创建新的 `batch_id`，不会覆盖或混入旧批次。证据只包含批次时间、文件相对身份和短 ID、选项配置、前后结构快照、验证结果、发布状态和结构化事件事实；不保存正文、密码、个人身份、完整绝对路径或本地化日志文本。

## 当前资格边界

本功能已有软件自动化测试和合成 PDF 结构验证记录。真实 Acrobat、签名验证、外部设备、监管专家复核和跨平台资格仍需在相应环境中单独完成；`signature_validity` 保持 `not_verified`，规则级验证仅限 PD-07 明确列出的检查，不代表完整资格。
