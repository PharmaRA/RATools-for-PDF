# 内容合规与安全性：清理规则

[返回手册首页](index.md)

入口：左侧“内容合规与安全性”。这些规则可能移除输出 PDF 中的导航、批注、附件或交互对象。先确定哪些内容应保留，再选规则；模块名称不表示处理后自动获得合规认证。

主批处理默认另存。若启用覆盖，清除内容会影响原文件；正式操作前应保留副本。

<a id="uri"></a>
## 删除外部 URI 链接

移除页面中的 URI 类型链接，例如网站和电子邮箱地址的可点击动作。文字一般仍在页面上。

外部 PDF 文件跳转不一定属于 URI，因此不能把此项当成“删除所有外部文件引用”。书签中的 URI 另由[清理书签外部链接](bookmarks.md#external)处理。

<a id="uri-black"></a>
## 删除外部 URI 链接并去色

在移除 URI 链接的同时，尝试把相关文本改为黑色。适合保留文字、取消外部跳转和链接色的场景。

与上一项二选一；当前界面会互斥选择。复杂文本或图像文字的去色结果需要视觉复核。

<a id="invalid"></a>
## 清理失效超链接

移除没有有效动作的空链接等结构性失效项目。它不是联网检测器，不能把服务器暂时不可达、网页返回错误或业务目标错误一概识别出来。

<a id="invalid-black"></a>
## 清理失效链接并去色

在清理失效链接时，尝试把相关区域文字变黑。与“清理失效超链接”二选一；文字仍保留，不会自动补写正确引用。

<a id="unknown"></a>
## 清理非标准动作链接

按支持的动作范围保留常见内部/外部跳转和执行动作，移除其他特殊行为。它不是完整的恶意内容扫描，也不保证清除所有可执行风险。

依赖特殊链接的资料应先试用，再实际点击导航检查。

<a id="dynamic"></a>
## 彻底清除动态内容 (JS/3D)

清理当前实现能够识别的 JavaScript 和动态交互对象，包括相关多媒体或 3D 内容。使用后，依赖脚本的表单计算、交互视图等可能不再工作。

应在目标阅读器检查原来包含交互内容的页面。不能把规则名称中的“彻底”解释为已完成所有安全检测或所有异常 PDF 情形的证明。

<a id="attachments"></a>
## 移除所有内嵌附件

清除 PDF 内部打包的嵌入文件，例如 ZIP、XML 或支持资料；不会删除磁盘上的外部链接目标。

先确认附件是否属于必须交付的资料。输出后检查阅读器附件面板；有需要的附件应在处理前由合适工具另行保留。

<a id="tags"></a>
## 移除结构化标签

删除结构树和标记信息。它通常不以改变可见文字为目的，但会影响结构化阅读、辅助技术和依赖标签的工作流。

若需要保留无障碍阅读或其他标签要求，不应仅为“清洁”而选择此项。文件仍可见不表示标签信息没有价值。

<a id="annotations"></a>
## 清理所有高亮/批注

移除可识别的普通非链接注释，例如便签、高亮、文本框和画笔对象。链接使用另外的规则管理。

已经展平进页面或扫描图像中的标记不能按普通批注对象删除。本项也不是对正文敏感信息的涂黑脱敏工具。处理后应检查批注面板和实际页面。

如果希望保留印章或高亮外观，应先考虑[展平批注](pages-fonts.md#flatten-annotations)，不要同时选择相反操作。

<a id="metadata"></a>
## 清空文档元数据

清理文档属性等元数据及相关 PieceInfo 信息，适用于不希望输出继续携带原标题、作者等属性的场景。

它不删除正文中的姓名、图片内文字、文件名或所有可能承载信息的对象，不能作为完整脱敏证明。输出后查看文档属性；不要同时要求[同步文件名为标题](initial-view.md#title)。

<a id="all-navigation"></a>
## 移除全部链接和书签

清除页面链接和整个书签树；普通批注并不因此全部删除。适用于明确不需要交互导航的副本。

此规则不会由“全选本页”自动选中。它与修改书签/链接的规则目标冲突；如果只想清理某一类链接，应使用范围更窄的规则。

## 清理后怎样复核

分别检查书签面板、附件面板、批注面板、文档属性，以及受影响页面上的实际文字和跳转。可以再次运行只读检测，但不能把“批注数为零”解释为“页面上已无任何审阅标记”。

有些规则具备有限的结构后置检查，其他规则仍可能显示未独立验证。详细含义见[结果与审计](logs.md#results)。
