# 书签管理

[返回手册首页](index.md)

入口：左侧“书签管理”。本页规则修改 PDF 书签面板中的项目；正文页面里的可点击区域由[超链接处理](links.md)管理。

勾选所需规则后执行主批处理。需要编辑书签标题、层级或指定目标，使用[书签 CSV 导入导出](data-exchange.md#bookmarks)。

<a id="zoom"></a>
## 书签设为承前缩放

对支持的内部页跳转或外部 PDF 跳转，将书签的固定倍率调整为承前缩放。读者放大到某个倍率后点击书签，通常可继续保持该倍率。

它不改变目标正文，也不设置文档首次打开倍率。处理后从不同放大比例点击几个书签，检查目标页和缩放；最终行为还取决于阅读器。

<a id="new-window"></a>
## 书签动作：新窗口打开

为指向外部 PDF/文件的受支持动作设置新窗口标记。它不会将同一 PDF 内的每个书签都改成新窗口，也不能控制系统浏览器的全部打开策略。

适合阅读主文件时需要保留当前窗口、再打开支持资料的场景。复核时应实际点击跨文档书签。

<a id="external"></a>
## 清理书签外部链接

当前实现删除 **URI 类型**的书签项目，例如网页链接。虽然名称包含“外部链接”，它不等于删除所有指向其他 PDF 或外部文件的书签。

删除的是匹配书签项目，不是删除目标网页或文件。若希望清除所有书签，应另看[移除全部链接和书签](cleanup.md#all-navigation)，并确认是否真的需要丢弃导航结构。

<a id="invalid"></a>
## 清理失效书签

清除程序判定为无有效目标或动作的书签。此处“失效”主要是 PDF 结构中的目标问题，不能据此保证每个外部目标的内容正确或始终可访问。

处理后检查多级目录与章节数量，特别是只作分组的父级条目及跨文档项目。若某个书签应当修复而非删除，可先导出 CSV、修正目标后导入。

<a id="unknown"></a>
## 清理非标准动作书签

按支持的动作类型筛选，移除不支持的特殊动作。常见内部跳转、外部文档跳转和启动文件动作与未知动作分开判断。

适合需要减少特殊交互行为的文档，但“非标准”不直接等于恶意。若资料依赖特殊导航，先在副本中处理并检查对应入口。

## 使用示例

需要统一一组资料的书签阅读体验，可先选“书签设为承前缩放”和“书签动作：新窗口打开”，再决定是否清理失效项目。不要为了统一样式而顺带删除全部导航。

输出后至少抽查一级与多级书签、末页目标、命名目标和外部文档跳转。折叠树的设置位于[初始视图与文档属性](initial-view.md#collapse)。
