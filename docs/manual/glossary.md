# 术语表

[返回手册首页](index.md)

| 名称 | 在本工具中的含义 |
| --- | --- |
| 队列 | 已添加到窗口的待处理文件集合；选中行与本次批处理范围不总相同 |
| 预检 | 只读检查输入，提示可识别的问题和建议 |
| 处理计划 | 执行前固定本批文件、规则、参数及执行/跳过决定 |
| 智能处理 | 利用预检筛选已选规则，不支持预检的规则仍可能执行 |
| 全部处理 | 执行全部已选规则，不等于选择软件的所有功能 |
| 发布输出 | 临时结果经允许后写入最终输出位置；不是上传到网络 |
| 书签 | 阅读器书签面板中的导航条目，可有多级和不同动作 |
| 页面链接 | 页面上的可点击区域，可指向本页/其他页、外部 PDF、网页或文件 |
| URI | 统一资源标识符，常见为网站和电子邮箱地址；不等同于全部外部文件跳转 |
| 承前缩放 | 跳转时沿用阅读时的缩放语义，具体表现受阅读器影响 |
| 命名目标 | 用名字定位的 PDF 跳转目标，不一定在数据中直接表现为一个页码 |
| 元数据 | 标题、作者等文档属性与相关结构信息，不是正文内容的总称 |
| 结构化标签 | 描述内容逻辑结构和阅读顺序等信息的标签树，可能与辅助阅读有关 |
| 展平 | 将某些可交互对象的外观固化到页面；不是删除其可见外观 |
| AcroForm | PDF 的交互表单结构；移除后可能失去填写/字段状态 |
| 线性化 | 重排文件结构，便于支持的环境逐步加载；也称快速网页浏览 |
| 对象流 | 压缩存放一组 PDF 对象的结构，属于 PDF 1.5+ 能力 |
| DPI | 图像按实际显示尺寸计算的每英寸像素密度；提高数值不自动增加原图细节 |
| JPEG 质量 | 有损编码质量参数，不是最终文档质量的百分比认证 |
| 打开密码 | 打开阅读 PDF 时所需的口令 |
| 权限密码 | 用于控制或修改打印、编辑等权限的口令 |
| 签名外观 | 页面上看见的印章或签字图形 |
| 数字签名有效性 | 与文档字节、签署身份、证书和信任判断有关，不能仅从外观推断 |
| 配置 / profile | 可携带规则、图像参数、ID 和版本的方案；不包含全部本机设置 |
| SHA-256 / 摘要 | 对内容计算的指纹，用于一致性检查；它本身不是身份签名 |
| 审计包 | 本工具对最近已结束主批次导出的四文件证据目录，不包含 PDF 正文 |
| `unknown` / `null` | 事实未知或没有观测值，不等同于零问题 |
| `not_verified` | 未完成对应独立验证，不等同于验证失败或验证通过 |
| 结构性检查 | 检查可打开性及部分 PDF 结构事实，不等同于视觉、业务或法规批准 |

需要具体操作时返回[工作导航](index.md)，不要仅依据术语定义决定是否处理正式文件。
