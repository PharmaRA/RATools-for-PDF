# 常见工作流程

[返回手册首页](index.md)

以下流程将功能组合成实际任务。每次先使用副本，先明确要保留什么，再决定删除、展平或转换哪些对象。

## 场景一：统一一批注册资料的阅读体验

1. 将输入副本集中到工作目录，把输出目录放在其外。
2. 拖入文件夹，核对队列数量、子目录和同名文件。
3. 运行预检，处理打不开、字体风险或异常目标等事项。
4. 根据团队规则选择预设或自定义组合；如使用 eCTD 预设，先确认删除批注、附件、动态内容及元数据是否符合本次任务。
5. 按需增加 A4/Letter、书签缩放或链接样式，不自动将所有模块全选。
6. 选择新的输出根目录，审阅计划并执行。
7. 查看失败/跳过文件，复核代表性页面和跨文档导航。
8. 导出配置、日志及需要的审计包，再开始下一批。

重点：地区预设不代替逐项要求核对；改文件名后，尤其要检查其他文件指向它的链接。

## 场景二：减小扫描 PDF 体积

1. 保留原始高分辨率版本，添加工作副本。
2. “全部取消”后只选择“文件级优化与输出 → 智能无损”，先处理一次。
3. 比较体积；如果不足，再从原始副本启用图像降采样，设置 DPI 和 JPEG 质量。
4. 在输出中放大检查最小字号、印章、手写字、细线和图表。
5. 记录最终参数与体积，保留满足用途的结果。

不要对已经压缩的输出连续多轮降低质量；也不要只因文件变小就认为可读性仍合格。参数解释见[图像压缩](compression.md#images)。

## 场景三：把审阅 PDF 整理成清洁副本

1. 先运行“文档检测 → 检测批注 (便签/高亮等)”。
2. 确定需要删除批注，还是保留其外观。两种目标选择不同规则。
3. 要删除时选“清理所有高亮/批注”；要保留外观时选“展平所有注释与批注”。
4. 不需要附件或元数据时再单独选对应规则。
5. 另存输出，检查批注面板和实际页面。

扫描或已展平的标记可能仍在页面上；这不是正文涂黑脱敏流程。不能以批注计数为零证明文档已完全清洁。

## 场景四：修正 Word 导出的引用错误

1. 添加 PDF，进入“文档检测”。
2. 执行“检测失效引用/链接文本”，记录页码和文案。
3. 回到对应 Word 原稿，修复交叉引用、书签或域。
4. 重新导出 PDF，用新文件替换本次待检对象。
5. 再次检测并人工点击关键引用。

此处检测的是可提取的固定错误文案。没有命中不能代替人工检查引用是否指向正确的业务内容。

## 场景五：修改一批 PDF 的书签

1. 队列只保留本次目标文件，导出书签 CSV 到新的数据目录。
2. 复制一份导出数据留底，在工作副本 CSV 中修改标题、层级或目标。
3. 保留文件名和相对目录，使用相同目标文件集合打开导入向导。
4. 确认每个 PDF 的匹配路径后导入。
5. 到队列首个文件目录下的 `RATools_导入完成` 检查新 PDF 的整棵书签树。

CSV 导入重建书签，不是自动追加。完整动作数据的 `Page` 与 `TargetPage` 起点不同，见[数据交换说明](data-exchange.md#bookmarks)。

## 场景六：解锁后再批处理

1. 在“安全中心 → PDF 解密与权限脱壳”建立独立队列。
2. 对需要打开密码的文件输入已知密码；不同密码分批。
3. 核对签名/表单选项，选择新输出目录并保留 `_decrypted` 后缀。
4. 等待结果，打开解锁副本确认。
5. 将副本加入主队列，再做预检和规则处理。

没有已知密码时不能把主批处理失败靠反复重试解决；应向有权提供密码的人获取所需信息。

## 场景七：字体风险交接

1. 根据预检结果选中工作副本，点击“嵌入缺失字体”。
2. 在外部程序使用可用且获授权的修复功能并保存。
3. 返回点击“保存后复检字体”，确认三类风险和可检查状态。
4. 人工核对中文、生僻字、希腊字母、上下标、符号及换行。

如果另存了新路径，需要把新文件作为对象重新检查。外部程序打开成功不等于嵌入成功。

## 场景八：交付一批文件及处理记录

1. 核对成功、失败、跳过、停止数量与输入清单。
2. 解决或明确记录未成功文件，不把缺失输出隐去。
3. 打开输出检查内容和关键导航。
4. 导出当前配置、CSV/TXT 日志和最近批次审计包。
5. 将 PDF 与证据分别归档，记录人工复核结论。

若需重试，先保存旧批次审计包，再重试并分别归档新批次。完整性核验、业务复核和批准是不同记录。
