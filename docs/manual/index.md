# RATools for PDF 使用手册

RATools for PDF 是面向药品注册资料整理的桌面 PDF 工具。你可以用它批量统一页面和阅读设置，整理书签、链接与批注，压缩文件，检查常见结构问题，并保留处理日志和批次证据。

第一次使用，先阅读[安装与更新](installation.md)，再完成[第一次处理 PDF](quick-start.md)。已经熟悉软件的用户，可以按下表找到任务，或进入[全部功能索引](feature-index.md)查找界面上的名称。

## 本手册的阅读约定

每个功能页说明入口、处理范围、操作步骤、保存结果及复核方法。主窗口的规则通常先勾选，再统一点击“开始处理”；字体手动处理、安全中心、数据导入导出和只读检测使用各自按钮。

“清理”“移除”是对输出 PDF 内部对象的处理。队列中的“移除选中项”和“清空”只是整理待处理列表，二者不是同一种操作。

默认批处理另存到所选目录下的 `RATools_Output`。独立工具的输出位置各不相同，详见[保存规则对照](files-and-output.md#saving)。处理完成后应打开实际输出文件复核，不能仅凭进度条或成功数量判断内容正确。

## 适用版本与范围

本手册于 **2026-11-23** 对照仓库 **v0.8.2 标识的当前源码**编写。发布包与源码不一定同步；以“关于”中的版本和对应发布说明为准。当前主要面向 Windows 10/11 桌面使用，其他平台不据此认定已完整验证。

中国/美国 eCTD 预设是便捷规则组合；预检、处理成功和结构性复检均不能替代业务审阅、目标阅读器检查或适用法规判断。当前自动字体嵌入不可用；页面工作台、图层套印和深度诊断没有普通用户入口。

仓库已有主界面截图来自较早布局，手册明确标注其用途。当前入口以正文按钮名称为准。
