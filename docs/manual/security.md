# 安全中心：密码、权限与签名限制

[返回手册首页](index.md)

入口：主窗口顶部“安全中心”，或队列右键“安全中心 (加解密)...”。它使用自己的文件选择、处理选项和输出路径；主窗口勾选的规则不控制这里的加解密任务。

<a id="encrypt"></a>
## PDF 加密与权限保护

该选项卡每次指定一个源 PDF 和一个输出文件。

1. 点击源文件“浏览...”，选择要保护的 PDF。
2. 检查“输出另存为”，默认建议在原目录使用 `_encrypted.pdf`，需要时改到新的位置。
3. 选择 256-bit AES 或 128-bit AES。界面将 256-bit AES 列为推荐选项；实际接收环境是否兼容需在目标阅读器确认。
4. 按需求勾选并设置打开密码和/或权限密码。
5. 设置打印、修改、复制提取和辅助功能权限。
6. 确认元数据明文和线性化选项，再点击“开始处理”。
7. 等待成功/失败提示，使用输出文件验证打开和权限行为。

### 两种密码的区别

| 类型 | 用途 |
| --- | --- |
| 打开密码（User Password） | 控制是否能打开阅读；未设有效打开密码时，不能认为阅读被限制 |
| 权限密码（Owner Password） | 用于权限控制或修改打印、编辑等限制 |

未设置有效密码时，程序会询问是否只应用无密码加密策略。加密标识本身不等于实现了口令访问控制。

### 权限与附加选项

打印可选择高质量、低分辨率或禁止；修改可选择禁止修改、页面装配、表单与电子签名、批注与表单、完全修改。另有复制/提取和屏幕阅读器辅助功能开关。

“保持元数据明文未加密”便于检索，但意味着文档属性信息可能仍可读取；它不会清空元数据。“启用 Web 快速视图”调整加载结构。

权限是否被遵守取决于阅读器实现，不能把禁止复制等选项当成无法绕过的防泄露保证。正式用途请在接收方使用的阅读器中验证。

<a id="decrypt"></a>
## PDF 解密与权限脱壳

1. 切换到“PDF 解密与权限脱壳”。
2. 用“添加文件”“添加文件夹”或拖拽建立本页队列，检查文件状态。
3. 仅有权限限制、无打开密码的文件可尝试免密处理；存在已知打开/权限密码时，勾选“包含已知打开/权限密码”并自行输入。
4. 检查签名限制和表单选项，尤其注意下节说明。
5. 选择“解密输出目录”，通常保留默认 `_decrypted` 后缀。
6. 检查线性化和对象流选项，点击“开始处理”，等待逐文件结果与成功/失败统计。
7. 打开输出确认，再将解锁副本加入主窗口队列继续预检或处理。

密码框对本次批量文件统一使用；密码不同的文件应分批。程序不破解未知密码，也不会在主规则队列弹出密码输入。

“保持原文件名 (覆盖输出)”会去掉后缀；如果输出映射回原位置，可能覆盖输入。即使有后缀，重复运行也可能替换同名解锁结果。使用新的输出目录可区分每次处理。

文件夹导入递归收集 PDF；输出按本批源文件相对目录组织。解密页的移除/清空仅整理该页队列。完成前等待安全中心工作线程退出，不要把窗口暂时无法关闭当作已经完成。

<a id="signatures"></a>
## 解除数字签名限制与表单字典

当前解密页“解除数字签名限制 (保留签名外观，解锁编辑)”初始为选中；“移除表单字典 (清除 AcroForm 交互状态)”初始未选中。执行前应主动检查，不要把默认选项当成对所有签名文档的建议。

签名外观是页面上看到的签字或印章。密码学数字签名还绑定原文档字节、签署身份、证书及信任判断。重写、解锁或固化外观后，即使印章仍在，也不能据此认定原数字签名有效。

移除表单字典会影响交互表单字段与状态，不能当成普通密码解锁的必要步骤。需要保留签署证据或可填写表单时，应保留原件，明确用途后再处理副本，并在目标阅读器独立检查。

## 常见失败

密码不匹配、源文件不可读、qpdf 不可用、输出不可写或路径冲突，都可能导致单文件失败。先查看本页状态和错误；不要只看整体操作结束。

安全中心结果与主批处理证据范围不同，不能认为每次加解密都会自动形成“日志 → 最近批次审计包”。
