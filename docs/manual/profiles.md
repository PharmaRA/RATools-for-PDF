# 预设与配置管理

[返回手册首页](index.md)

快速预设帮助复用规则；它不决定是否覆盖文件，也不替你运行任务。当前“保存为我的常用”和 JSON 导入导出位于快速预设栏的 **配置管理** 菜单内。

<a id="builtins"></a>
## 中国 eCTD 与美国 eCTD

点击“中国eCTD”或“美国eCTD”，然后检查各模块已选规则。两者是应用提供的便利组合，不能当作当前监管要求的完整清单或官方认证。

当前两套预设共同包含 13 项：

| 规则类别 | 共同选择 |
| --- | --- |
| 打开设置 | 设为首页打开、重置页面布局、设置导览标签 |
| 书签 | 书签设为承前缩放、书签动作：新窗口打开 |
| 页面链接 | 超链接设为承前缩放、链接动作：新窗口打开 |
| 清理 | 清理所有高亮/批注、清空文档元数据、移除所有内嵌附件、彻底清除动态内容 (JS/3D) |
| 文件 | PDF版本转换、启用线性化 (快速网页浏览) |

“中国eCTD”另增加三项，共 16 项：删除外部URI链接、折叠所有书签、eCTD文件名合规格式化。“美国eCTD”保持上述 13 项。

这两套预设都不自动选 A4/Letter、图像降采样或自动字体修复。地区名称不意味着某个预设自动处理所有当地需求。预设包含删除批注和附件等操作，执行前必须确认这些内容确实应从输出移除。

<a id="favorite"></a>
## 保存并使用“我的常用”

1. 按本次需求选择规则和图像参数。
2. 点击“配置管理 → 保存为我的常用”。
3. 以后点击“我的常用”恢复这一组合。
4. 确认参数及规则后，再进入处理计划。

常用配置保存规则与图像参数。旧版本的常用规则可以按程序支持的格式迁移；需要正式跨机器共享时，建议用下面的 JSON 导出。

<a id="export"></a>
## 导出配置 JSON

点击“配置管理 → 导出配置 (JSON)...”，选择一个新的文件名。当前配置导出不覆盖已有文件，需要保留修订时请换名。

JSON 包含规则、参数、配置 ID/版本及来源说明等，不包含输出目录、覆盖原件、自动打开目录、并行数、每文件超时和主题。接收者导入后仍需自行设置这些本机选项。

<a id="import"></a>
## 导入配置并核对差异

1. 点击“配置管理 → 导入配置 (JSON)...”。
2. 选择配置文件。
3. 在“配置差异预览”中查看 ID/版本、地区、增加/移除的规则和参数前后值。
4. 确认后应用；取消则不改变当前规则及参数。

未知规则、错误类型、越界参数、未来格式版本、重复字段和冲突组合会被拒绝，不会自动替换为近似方案。遇到拒绝，优先请发送者从兼容版本重新导出，不要删去不理解的字段强行导入。

<a id="conflicts"></a>
## 常见冲突与参数要求

| 情况 | 处理方式 |
| --- | --- |
| A4 与 Letter 同时选择 | 选择一种目标纸型 |
| 展平批注与删除批注同时选择 | 决定保留外观还是移除注释 |
| 同步标题与清空元数据同时选择 | 决定是否保留标题 |
| 加黑框、蓝框标准化、清除边框相互冲突 | 选择明确的最终外观；两种蓝框标准化可配对 |
| 删除全部链接书签，又要求修改它们 | 删除或保留修改二选一 |
| 单独导入某个隐藏压缩规则 | 使用界面支持的完整“不压缩/智能无损/极限无损”组合 |
| 图像 DPI 或质量越界 | DPI 72–600；JPEG 质量 1–95 |

## 配置身份和重启行为

应用内置或导入配置后，如果再改实际规则或图像参数，当前组合将按自定义配置记录。仅改变输出目录等本机设置不等于更改规则配置。

程序重启会恢复保存的规则状态，但不会保证仍以原预设按钮/身份呈现；需要明确使用某个方案时，重新应用该预设或“我的常用”。

批次证据保存实际配置及摘要；相同名称不保证内容相同。格式字段和维护说明见[版本化配置技术说明](../profiles.md)。
