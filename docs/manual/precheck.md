# 预检与文档检测

[返回手册首页](index.md)

两类检查都不会修改源 PDF。“预检”服务于后续规则选择；“文档检测”针对批注和 Word 失效引用文本给出专门报告。

<a id="precheck"></a>
## 运行预检

1. 添加需要检查的 PDF，核对整个队列。
2. 点击底部“预检”，等待逐文件状态和汇总。
3. 打开“日志”，查看建议、错误及字体/批注/引用相关信息。
4. 需要表格留档时，点击“导出预检结果”，保存 CSV。

结果中的“建议处理”表示发现当前检查能够识别的事项；无法打开或检查失败的文件需要单独处理。“没有建议”不意味着所有内容正确，也不代表所有规则都能被预检判断。

预检会检查多种文档属性、书签、链接、清理对象和字体风险。某些发现只是需要人工复核的信息，例如外部目标问题和字体风险，不一定对应可自动勾选的修复规则。

<a id="suggestions"></a>
## “应用建议”和“处理建议文件”

| 按钮 | 改变什么 | 不会替你完成的事 |
| --- | --- | --- |
| 应用建议 | 将最近预检中可映射到界面规则的建议勾上 | 不开始处理；不自动解决字体等外部工作流 |
| 处理建议文件 | 以最近预检中有可处理建议的文件作为本轮输入 | 不保证只执行每个文件自己的建议；仍按当前已选规则与处理模式生成计划 |

“应用建议”不是先清空再重建规则。你先前选择的其他规则可能仍保留；应用后应查看各模块和总规则数，再决定是否开始。

队列改变或完成处理后，旧预检可能失效；遇到“预检结果已失效”应重新预检。不要反复点击建议按钮试图沿用旧结果。

<a id="modes"></a>
## 智能处理与全部处理

智能处理只对能够预检判断的已选规则进行筛选：命中则执行，未命中则可能跳过。不支持预检的规则仍可能执行。A4 页面适配就是不能仅凭预检精确判断的例子。

“全部处理”表示执行全部已勾选的规则，不是自动勾选所有功能。两种模式都应审阅开始前的[处理计划](processing.md#plan)。

<a id="annotations"></a>
## 检测批注（便签/高亮等）

进入“文档检测”，点击“检测批注 (便签/高亮等)”。它扫描整个队列，而非仅选中行，弹窗列出命中与失败文件，并将结果写入日志。

这适合确认文档是否仍有可识别的注释对象。若标记已经被展平为页面内容或属于扫描图像，它不再是普通批注对象，不能指望此按钮将其识别为可删除批注。

需要去掉批注，之后另选[清理所有高亮/批注](cleanup.md#annotations)并执行；需要保留外观，则阅读[展平批注](pages-fonts.md#flatten-annotations)。

<a id="broken-references"></a>
## 检测失效引用/链接文本

同页点击“检测失效引用/链接文本”。它查找 Word 转 PDF 后残留的固定错误文案，例如：

```text
错误！未找到引用源。
错误！未定义书签。
Error! Reference source not found.
Error! Bookmark not defined.
```

检测会报告命中页码和文案样例；正文中普通的“错误”或“error”不是匹配目标。它不是访问所有网页的网络有效性检测，也不执行 OCR；没有可提取文字的纯扫描页不能据此认为没有引用错误。

发现问题后，通常应回到 Word 原稿修复域或交叉引用，重新导出 PDF，再运行检测。这个按钮本身不会重建引用。

## 如何保存和理解结果

预检 CSV 提供文件、状态、建议、错误及字体/批注/失效引用细节。独立检测的弹窗和日志适合查看明细；需要完整文本时导出 TXT 日志。

看到“检测失败”必须保留这个事实，不应与“未发现相关内容”合并统计。需要正式使用前，仍应抽查实际页面、书签目标和关键链接。
