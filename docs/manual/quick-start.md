# 第一次处理 PDF

[返回手册首页](index.md)

这次练习用一份不含敏感信息、无需打开密码的 PDF 副本，完成“导入 → 只读预检 → 选规则 → 确认计划 → 另存 → 复核”。练习不需要先掌握全部功能。

## 1. 准备输入和输出位置

准备一份 `练习报告.pdf` 的工作副本，以及一个空的练习输出目录，例如 `D:\PDF练习\结果`。打开“全局设置”，确保没有选中“覆盖原始文件 (不推荐)”。

## 2. 添加 PDF

将副本拖进主窗口，或点击“选择 PDF 文件”；队列已有文件时，也可使用队列工具栏的“文件”按钮。确认队列只包含这次练习文件。

点击“开始处理”会处理本次队列，单纯选中某一行不会把批处理限定为这一行。因此练习前应移除不相关队列项。

## 3. 先做一次预检

点击“预检”，等待汇总。预检只读，不会修复文件，也不会生成处理后的 PDF。

打开“日志”查看建议和失败原因。若需要打开密码，先结束本练习并按[安全中心](security.md)生成解锁副本；不要将“无法检查”视为“没有问题”。

## 4. 选择两条容易观察的规则

点击快速预设栏“全部取消”，进入“初始视图与文档属性”，勾选：

- “设为首页打开”；
- “同步文件名为标题”。

保持“智能处理”。若文件本来已满足某条规则，计划可能显示跳过，这是正常结果。第一次练习无需勾选“中国eCTD”的全部规则。

## 5. 选择输出目录并确认计划

点击“开始处理”，选择之前准备的 `D:\PDF练习\结果`。程序会把结果组织在其下的 `RATools_Output` 中。

在“处理计划预览”查看文件及每条规则的“预检”“计划”“原因 / 风险”。确认对象和规则正确后，点击“确认计划并开始”。如果发现选错文件或规则，点击“取消”，返回调整。

若文件带签名或启用了文件名格式化，可能先出现相应确认提示；本练习无需主动开启这些选项。

## 6. 打开真正的输出文件

等待结果汇总。若开启了自动打开输出目录，资源管理器会打开结果位置；否则在所选目录下找到 `RATools_Output`。

打开输出的 `练习报告.pdf`，检查：

1. 能否正常打开，页数是否一致；
2. 阅读器重新打开时是否从第一页开始；
3. 文档属性中的标题是否为 `练习报告`；
4. 正文、图表和原有跳转是否正常。

队列仍代表输入文件，双击队列项通常打开原始路径；不要把原件当成处理结果检查。阅读器也可能记住自己的上次阅读位置，必要时关闭文档后重新打开并检查文档属性。

## 7. 留下本次记录

点击“日志”，查看文件状态和结果/变化。需要留档时导出日志；需要结构化批次证据时，点击“导出最近批次审计包”。开始下一批或重试前，先导出当前需要保留的批次。
