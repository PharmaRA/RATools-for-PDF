# 页面与字体标准化

[返回手册首页](index.md)

本页包含四条批处理规则，以及独立的字体手动交接按钮。页面尺寸处理和字体修复是不同工作；选中页面规则不会自动嵌入字体。

<a id="a4"></a>
## 适配到 A4 尺寸

入口：“页面与字体标准化 → 适配到A4尺寸”。A4 为 210 × 297 mm。处理按页面方向等比适配并居中留白，不是直接截去超出纸张的内容。

适用于需要统一纸型的资料。大幅图表缩小到 A4 后可能变得难读；请检查横向页面、细小文字、页边缘、链接区域和批注位置。智能模式不保证跳过这条规则。

<a id="letter"></a>
## 适配到 Letter 尺寸

Letter 为 8.5 × 11 英寸，约 215.9 × 279.4 mm。同样按原页面方向等比缩放并居中。

A4 和 Letter 在界面互斥，只选择本批真正需要的纸型。改变纸型不等于符合某个地区的全部递交要求，也不增加原图像的细节。

<a id="rotation"></a>
## 展平页面物理旋转角

把页面旋转角归一到 0°，用于减少后续打印、盖章或坐标处理对旋转属性的依赖。目标是保留阅读方向，并改变内部表达方式；它不是“把所有页面顺时针旋转 90°”工具。

处理后检查原来旋转的页面、横向表格和链接点击位置。不能只根据旋转属性已为 0° 判断可视内容正确。

<a id="flatten-annotations"></a>
## 展平所有注释与批注

将批注、高亮、印章等注释的外观固化到页面中，减少其作为独立交互对象被隐藏或修改的可能。此后普通批注列表可能不再列出它们，但页面仍看得见相应标记。

如果目标是删除审阅痕迹，应使用[清理所有高亮/批注](cleanup.md#annotations)。先展平再删除普通批注通常无法去掉已经变成页面内容的外观。

不要同时选择展平和删除批注。对于签名文件，固化签名外观也不保留密码学签名有效性，详见[安全中心](security.md#signatures)。

<a id="fonts"></a>
## 嵌入缺失字体：手动交接与复检

范围：主队列中选中的 PDF。当前没有可用的自动字体修复功能。

1. 先运行[预检](precheck.md)，查看字体风险。
2. 在队列中选中需要处理的 PDF，进入本模块，点击“嵌入缺失字体”。
3. 在“手动嵌入缺失字体”窗口点击“打开 Acrobat”。未找到 Acrobat 时，程序可能尝试系统默认 PDF 程序。
4. 在具有相应功能的 Acrobat 中，按“所有工具 → 印刷制作 → 印前检查”寻找“嵌入缺失的字体”，由你执行修复并保存。外部版本和许可不同，菜单及可用功能可能不同。
5. 回到仍打开的对话框，点击“保存后复检字体”。
6. 确认本次文件可检查，且未嵌入、替代风险、状态未知三类计数均为零；随后打开 PDF 检查关键文字。

外部程序打开的是选中文件的路径；如果对原路径执行保存，可能直接改变该工作文件。希望保留原件，应先把副本加入队列后操作。如果外部程序另存到另一条路径，当前对话框仍复检最初选择的文件；需要改用新文件重新发起检查。

## 字体结果怎么理解

| 结果 | 含义与下一步 |
| --- | --- |
| 未嵌入 | PDF 内缺少相应字体程序；由外部工具按许可和可用字体处理 |
| 替代风险 | 可能使用替代字体；检查字形、字符和布局 |
| 状态未知 / 不可检查 | 不能确认结构状态，不得当成零风险 |
| 三类计数为零且可检查 | 本次结构性复检通过；仍需视觉检查 |

零风险不证明本轮确实实施过修复，也不证明中文、生僻字、上下标、符号和换行完全正确。字体是否允许嵌入还取决于授权。安装 Acrobat、看到按钮或成功启动程序都不等于修复已经完成。

当前能力及技术边界见[字体 provider 说明](../font-providers.md)。
