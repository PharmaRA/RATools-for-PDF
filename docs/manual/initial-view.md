# 初始视图与文档属性

[返回手册首页](index.md)

入口：左侧“初始视图与文档属性”。勾选所需规则后，按[执行批处理](processing.md)统一执行。本页调整 PDF 中的打开设置和标题，不负责重新排版正文。

<a id="first-page"></a>
## 设为首页打开

把文档打开动作设为第一页，并采用阅读器默认缩放。适合希望接收方从封面开始阅读的资料。

结果应关闭后重新打开检查。阅读器自身的“恢复上次阅读位置”可能影响观察；这条规则不删除页面，也不改变页面顺序。

<a id="layout"></a>
## 重置页面布局

移除文档显式指定的页面布局，让阅读器采用默认布局。它不等于强制单页、连续滚动或双页，也不改变 A4/Letter 尺寸。

适合消除文档携带的不合适初始布局；如果不同阅读器表现不同，应检查各自默认设置。

<a id="zoom"></a>
## 重置缩放比例

清除固定的初始倍率，使用默认缩放。当前实现会同时把打开动作指向第一页，因此不能用它实现“保留第 20 页作为打开页，只改倍率”。

它不修改书签或正文链接的跳转缩放。后两者分别使用[书签承前缩放](bookmarks.md#zoom)和[超链接承前缩放](links.md#zoom)。

<a id="navigation"></a>
## 设置导览标签

有书签时设置为显示书签面板和页面；没有书签时设置为页面视图。这不会自动创建目录或书签。

如果同批又删除书签，最终应检查输出的书签树和面板表现，不能只依据执行前存在书签作判断。

<a id="collapse"></a>
## 折叠所有书签

将书签树设置为折叠状态，减少打开文档时展开过多层级。书签标题与目标仍需要保留并检查。

处理后在阅读器展开几项多级书签，确认层级和跳转正常。“折叠”与“删除失效书签”不是同一操作。

<a id="title"></a>
## 同步文件名为标题

将输入文件名去掉 `.pdf` 后写入 PDF 文档属性的标题。例如 `Study Report.pdf` 的标题设为 `Study Report`。这不是修改正文标题，也不是将作者和主题全部清空。

若同时启用 eCTD 文件名格式化，输出名称可能已变为 `study-report.pdf`，标题仍来自本轮输入名称，不应假定二者完全相同。

不要同时选择“清空文档元数据”来期待保留新标题；配置校验会拒绝此类冲突。若需要标题且要处理其他元数据，应先明确目标，不使用互相抵消的方案。

## 一个常见组合

需要统一阅读体验时，可以选择首页打开、重置页面布局、设置导览标签和折叠书签，再根据业务需要决定是否同步标题。保存后检查文档属性、首次打开视图以及多级书签，而非只检查文件是否能打开。
