# 文件与保存规则

[返回手册首页](index.md)

## 添加与整理队列

点击“文件”选择一个或多个 PDF，点击“文件夹”递归收集所选目录及子目录中的 PDF，也可以直接拖入文件或文件夹。程序只收集 `.pdf`，重复添加相同路径不会生成重复队列项；不同目录的同名文件仍是不同输入。

处理前核对队列数量和目录层级。输出目录若位于后来拖入的文件夹内，其中的 PDF 也可能再次被收集，建议把输入和结果目录分开。

| 操作 | 结果 |
| --- | --- |
| 右键 → 移除选中项 | 从队列移除所选文件或文件夹下项目，不删除磁盘文件 |
| 队列工具栏 → 清空 | 清空待处理列表，不删除源文件 |
| 右键 → 定位到文件位置 | 在系统文件管理器中定位所选路径 |
| 右键 → 查看文件详情... | 查看所选文件或文件夹信息 |
| 双击文件 | 用系统默认程序打开输入路径 |
| 右键 → 安全中心 (加解密)... | 将所选文件带入独立安全工作流 |

预检、文档检测和数据导入导出期间队列冻结。批处理期间不允许移除或清空；即使允许追加文件，已经启动的批次也使用启动时的文件清单，新追加项应留到下一次明确执行。

## 各功能保存到哪里

| 功能 | 是否修改 PDF | 结果位置与原件影响 |
| --- | --- | --- |
| 预检、文档检测、文件详情 | 只读 | 结果显示在界面/日志；预检 CSV 需另行导出 |
| 主窗口规则处理，默认另存 | 是，生成结果 | 所选根目录下的 `RATools_Output`，保留本批源文件的相对目录关系 |
| 主窗口规则处理，启用覆盖 | 是 | 确认后写入原文件路径；即使选中文件名格式化，也不会实际重命名原文件 |
| 书签 CSV / 链接 JSON 导出 | 不修改源 PDF | 用户选择的数据目录，文件名含 `_bookmarks.csv` 或 `_links.json` |
| 书签 CSV / 链接 JSON 导入 | 生成新 PDF | 队列首个 PDF 所在目录下的 `RATools_导入完成`，再按相对目录组织 |
| 安全中心加密 | 生成加密 PDF | “输出另存为”指定的路径，自动建议 `_encrypted.pdf` |
| 安全中心解密 | 生成解锁 PDF | 解密页选择的目录，默认添加 `_decrypted` 后缀 |
| 字体手动处理 | 由外部程序决定 | 取决于外部程序保存的位置；复检读取对话框最初选中的路径 |
| 日志/预检结果导出 | 不修改 PDF | 用户指定的 CSV 或 TXT 文件 |
| 最近批次审计包 | 不修改 PDF | 所选目录下新建 `RATools_Audit_日期时间_随机ID` 目录 |

全局默认保存位置是选择目录时的初始位置，不会统一接管所有独立工具的输出。安全中心、数据导入和字体处理都应看自己的路径设置。

## 相对目录示例

假设同一批输入为：

```text
D:\资料\a\report.pdf
D:\资料\b\report.pdf
```

主批处理选择 `D:\结果`，结果按公共输入目录保留层级：

```text
D:\结果\RATools_Output\a\report.pdf
D:\结果\RATools_Output\b\report.pdf
```

相对层级取决于本次文件集合的公共目录，不是永远保留整个磁盘路径。只有一个输入、换一组文件或跨盘符时，不应照搬示例推测路径；以实际预览、输出目录和日志为准。

## 原件和已有输出

默认另存可保留输入原件，但不表示已有的同名输出会被自动版本化。成功处理可能替换相同目标路径的旧结果；每一轮需要独立归档时，请选择新的输出根目录。

主批处理先写临时结果，检查允许后再发布；失败、停止或有效跳过会保全原先已有输出。它不是整批事务：已经成功发布的文件不会因后续某个文件失败或用户停止而自动撤销。

“覆盖原始文件 (不推荐)”需要明确确认，不能依靠关闭窗口或撤销按钮恢复原件。处理前自行保存原件副本；不要把应用内部临时目录当作用户备份。

## 处理后找不到结果

先看文件终态：失败、已停止、已跳过未必产生新输出。检查你进入的是 `RATools_Output`、`RATools_导入完成` 还是安全中心指定目录，并留意是否启用了文件名格式化。详细步骤见[常见问题](faq.md)。
