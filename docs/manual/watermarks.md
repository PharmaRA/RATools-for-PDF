# 去除水印

[返回全部功能索引](feature-index.md)

入口：主窗口 **内容合规与安全性 → 去除水印…**。这是独立的单文件工具，不属于批处理规则或 eCTD 预设。选中队列中的 PDF 后打开会自动填入文件，也可以在窗口内选择文件。

## 操作步骤

1. 选择 PDF，输入处理页码，例如 `1-3,5`；留空处理全部页面。
2. 点击“分析对象”。列表按页码显示可独立移除的批注、文字、图片和绘图对象，默认全部不选。
3. 勾选需要去除的对象，查看右侧原始页面与处理后页面。列表也可能包含正文、正常批注、页眉或公司标识，需要自行判断；勾选并不表示已修改文件。
4. 对所有包含勾选对象的页面查看当前选择的预览。切换预览页码可检查其他页面，修改选择后需要重新确认。
5. 勾选“已检查所选对象的预览”，点击“另存为 PDF…”，使用新的文件名。窗口会报告所选对象数量和输出路径。

原件及已有输出均不覆盖。保存前后检查原文件是否发生变化，输出先保存到临时文件，重新打开并比较页数、尺寸及修改页的渲染，再发布到新路径。失败或取消时，本任务创建的临时文件移入回收站；回收失败时保留文件并报告失败。

## 首版范围

| 类型 | 支持边界 |
| --- | --- |
| 批注水印 | 选择可枚举的普通批注、印章等；链接、表单和复杂内嵌批注不列入候选。 |
| 简单独立文字 | 完整文字对象中只有一次普通文字绘制；保留字体、颜色等状态，移除选定绘制指令。 |
| 图片 | 移除指定页面上的一次独立图片绘制；共用同一图片的其他位置保持。覆盖页面面积达到 90% 的图片不列入候选。 |
| 绘图 | 独立路径绘制或页面直接引用的组合绘图对象。组合对象作为整体选择，不拆分其中的正文与水印。 |

同一图片或组合对象在多页重复使用时，需要分别选择对应页面的对象。首版不提供自动认定水印、跨文件批量匹配或扫描图像修复。

多次文字绘制、隐藏 OCR 文字、文字裁剪、内联图片、部分复杂内容流会跳过，窗口显示相关提示。含复杂指令的页面可能仅提供批注候选。无法分离的内容不做猜测性修改；不以“涂白一个矩形”的方式去除覆盖正文的水印。

需要打开密码的文件请先通过安全中心解锁。需要修复才能读取的 PDF 暂不处理。修改副本不保留原数字签名的有效性。
