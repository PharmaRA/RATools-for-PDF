# Screenshots

This directory stores repository-owned screenshots used by `README.md` and other project presentation docs.

Current assets:

- `main-window.png` - main application window captured from the PySide6 desktop UI.

Guidelines:

- Prefer real application screenshots over mockups.
- Avoid including sensitive PDF names, patient data, regulatory submission identifiers, or local user paths.
- Keep screenshots reasonably sized so GitHub README rendering stays fast.
