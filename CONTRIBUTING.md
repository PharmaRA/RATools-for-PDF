# Contributing

感谢关注 `RATools-for-PDF`。  
Thank you for your interest in `RATools-for-PDF`.

## Scope / 适用范围

- 欢迎提交 bug 修复、文档改进、测试补充和小范围体验优化。
- Bug fixes, documentation improvements, additional tests, and focused UX improvements are welcome.
- 如果改动会影响功能范围、处理规则或发布方式，建议先开 Issue 讨论。
- If a change affects feature scope, processing rules, or release behavior, please open an issue first.

## Local Setup / 本地准备

1. 安装 Python 3。
2. Run `pip install -r requirements.txt`.
3. Run `python -m unittest discover -s tests -p "test_*.py" -v` before opening a pull request.

## Pull Requests / Pull Request 说明

- 小而清晰的 PR 更容易审核和合并。
- Smaller, focused pull requests are easier to review and merge.
- 请在描述里写清楚修改原因、影响范围和验证方式。
- Please describe the motivation, scope, and validation steps in the PR.

## Review Expectations / 维护者预期

- 这是一个个人主导维护的项目，Issue 和 PR 的响应时间为尽力而为。
- This is a personal-maintainer-led project, so issue and PR response times are best-effort.
- 维护者可能会根据长期维护成本调整方案或拒绝超出当前方向的改动。
- The maintainer may adjust or decline changes that do not fit the current roadmap or maintenance budget.
