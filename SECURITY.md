# Security Policy

## Reporting / 报告方式

- 请不要在公开 Issue 中直接披露未修复的安全问题。
- Please do not disclose unpatched security issues in public issues.
- 建议通过私下渠道联系维护者，并提供可复现信息。
- Please contact the maintainer privately and include enough detail to reproduce the issue.

## What To Include / 建议提供的信息

- 影响版本
- 触发条件
- 复现步骤
- 影响范围或潜在风险
- 如有可能，提供最小示例文件或截图

## Response Expectations / 响应预期

- 这是个人维护项目，安全问题响应为尽力而为，不提供 SLA。
- This is a personal-maintained project, so security response is best-effort and no SLA is provided.
- 在问题确认和修复前，请避免公开传播可直接利用的细节。
- Please avoid public disclosure of directly exploitable details before the issue is confirmed and fixed.
